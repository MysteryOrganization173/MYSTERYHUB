# Supabase

This directory contains Supabase-related configuration, migrations, and seed data.

## Structure

```
supabase/
  migrations/     — SQL migration files (auto-generated by Supabase CLI)
  seed.sql        — Seed data for local development
  config.toml     — Supabase project configuration
```

## Setup

1. Install the Supabase CLI: https://supabase.com/docs/guides/cli
2. Run `supabase init` to initialize the project
3. Run `supabase start` to start local Supabase instance
4. Copy your project credentials into `.env.local`
